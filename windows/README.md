# Codex 余量 · Windows

从项目 Releases 下载 CodexQuota-Windows.exe，双击运行。版本 1.4。也可以使用本目录的 build.ps1 自行构建。

本程序使用当前 Windows 账户已安装并登录的 Codex，查询在线账户余量与重置券。无需打开命令行；组件不显示在任务栏。登录和组件位置、主题等设置沿用原有数据。

点击“储备”或按 F9 查看重置券并确认使用。服务器确认成功并读取最新额度后，确认弹窗收起，原来的 **5 小时与每周额度条**用约 1.2 秒恢复，启动干脆，随后逐渐减速、平稳停下；百分比和大尺寸下的额度圆环一起增长。动画期间显示稳定的整百分比，完成后恢复真实小数精度；数字采用等宽数字，避免宽度跳动。条内只有很淡的静态高光。恢复到服务器返回的真实余额，返回满额度时两条回满。

最初的扩散光环、小光点及按钮轻微回弹已恢复，同时加入双侧柔和彩纸礼炮。点击确认会有一声轻触音，重置确认并取回额度后播放柔和的上行音。礼炮约 1.6 秒淡出，不闪屏或移动窗口。右键或点击「…」菜单，可以分别关闭 **重置音效** 和 **彩纸礼炮**；关闭彩纸仍保留最初的光环和额度恢复。音效已内置在 EXE，遵守系统音量，不需要额外文件。系统关闭动画时直接显示真实额度。

网络失败、没有可重置窗口或没有可用重置券时，保留真实额度。兑换确认后若最新用量读取失败，会提示再次同步。每次逻辑兑换复用同一个请求编号，避免重试造成重复兑换。

现有玻璃材质、拖动和收起展开方式保留。验证使用模拟账户，没有消耗真实重置券。
