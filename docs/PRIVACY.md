# 数据与隐私

本应用读取账户额度和重置券，不提交模型推理或 ChatGPT 对话。兑换只由用户在确认界面发起。应用没有遥测或第三方分析服务。

## Android

登录在系统浏览器的 OpenAI 官方页面完成。授权采用 state、nonce 与 PKCE，验证 ID token 后才保存会话。密码不会输入到本应用。令牌通过 Android Keystore 的 AES-GCM 加密保存在应用私有目录，系统备份关闭。

额度缓存、最近 7 天的采样记录、偏好和选取的背景图只存在本机。退出账户会清除本机登录凭据；不同账户的缓存与兑换请求编号分开保存。未知数据不猜测，离线保留最后同步时间。

应用访问固定的 OpenAI HTTPS 登录与账户服务；浏览器授权使用本机 loopback 回调。完整路径和校验流程见 [PROTOCOL.md](../android/PROTOCOL.md)。

选择背景图片通过系统文件选择器，不读取所有照片。分享额度卡片仅在点击分享时生成，由用户在系统分享菜单中选择接收应用。

## Windows

通过本机已登录的 Codex app-server 查询在线账户数据，组件不打包、不上传 Codex 登录凭据。配置和未确认兑换的编号保存在当前用户的 `%LOCALAPPDATA%/CodexUsageWidget`。

实时玻璃效果会在内存中采样组件背后的屏幕区域进行模糊处理；该背景图像不保存、不上传。额度接口与玻璃绘制彼此独立。

## 开源与发行

仓库和安装文件不包含真实登录会话、账户配置、访问令牌、授权日志或 APK 发行签名私钥。示例截图和自动测试使用模拟账户。公开报告问题时请参考 [SECURITY.md](../SECURITY.md)，先移除敏感信息。
