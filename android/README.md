# Codex 余量 · Android

用于个人账户的安卓 Codex 用量与储备重置工具。Android 8.0（API 26）及以上，APK 无需电脑常驻，也无需安装 Codex CLI。

## 首次使用

1. 将 `CodexQuota-Android.apk` 传到手机，打开并安装。系统询问时，允许当前文件管理器安装应用。
2. 打开 **Codex 余量**，点击 **继续使用 ChatGPT**，在手机浏览器的 OpenAI 官方页面完成登录与授权，再返回应用。
3. 授权采用 Codex 开源账户流程；官方页面可能显示 **Codex / Codex CLI**。本工具是独立的个人应用。
4. 如果浏览器无法返回，点击 **改用一次性设备码登录**。先在 ChatGPT 安全设置中启用设备代码登录，在官方页面输入应用刚生成的代码。
5. 首次同步后会显示账户的额度窗口、剩余百分比、下次重置时间和可用储备次数。未知数据用 `—` 表示。

手机网络需要能访问 OpenAI 的登录和 Codex 账户服务。登录期间会出现一条临时通知，用于保留浏览器回调与设备码验证；登录结束后关闭。

## 储备重置

在概览中点击 **查看与使用重置券**。查看数量和最早到期日期后，点击 **使用 1 次储备**，才会提交兑换。兑换重置符合条件的额度窗口，结果由服务器决定。

每次逻辑兑换使用一个 UUID。提交之前将编号保存到本机；网络中断或结果不明确时保留原编号，再次确认会重试同一次兑换。重启应用不会自动兑换。成功后重新读取真实额度，不在手机上猜测更新后的余额。

服务器确认重置成功并取回最新用量后，自动回到概览。原有的 **5 小时和每周额度条**从之前的余额恢复至服务器返回的余额，百分比同步增长；过程约 1.2 秒，启动干脆，随后逐渐减速并平稳停下，不反弹。两端采用相同的曲线，条内只有很淡的静态高光，玻璃材料保持原样。服务器返回满额度时两条回满；未重置的窗口保留真实值，读取失败时保留最后一次数据并提示再次同步。

点击确认会响起短促的轻触音；确认重置并读取到新余额后，最初的扩散光环和小光点再次出现，伴随双侧柔和彩纸和约 1.3 秒的上行音。礼炮约 1.6 秒自然淡出，不闪屏、不摇晃界面。设置中的 **重置时刻**可以分别关闭彩纸和音效；关闭彩纸仍保留光环和额度恢复。音效为原创合成的短音，遵守手机静音与系统音量；系统关闭动画时直接显示真实余额。**先体验界面与动效**使用明确标记的示例账户，可以预览全部反馈，不消耗真实重置券。

## 桌面小组件

在概览点击 **添加桌面小组件**，选择 **玻璃卡片** 或 **玻璃胶囊**。也可长按手机桌面，打开小组件列表，找到 Codex 余量。

- 卡片显示两个额度窗口、倒计时、最后同步时间及储备入口。
- 胶囊显示紧凑额度；调整为较窄、较高的形状时上下排列。
- 点击刷新图标直接启动短暂的同步服务，完成后自动结束，**无需打开主界面**。点击卡片打开应用，点击储备进入兑换确认。
- 在设置中可以隐藏桌面上的数字，选择主题、点缀色及背景图片。

应用和小组件保持相同的半透明材料、连续圆角、柔和阴影和高光。应用内的模糊纹理随背景与视差移动。第三方桌面小组件受安卓桌面渲染能力限制，不能直接实时模糊背后的壁纸；可以选取同一张壁纸作为背景，生成预先模糊的玻璃材料。选择图片使用系统文件选择器，不需要访问全部照片或屏幕录制权限。

## 刷新、提醒与记录

应用在前台默认 **30 秒**刷新，可选 15 / 30 / 60 秒。后台默认 **15 分钟**同步，可选 15 / 30 / 60 分钟。周期任务保持原来的排期，开机和更新应用后恢复；桌面系统还提供每 30 分钟的恢复检查。安卓可能因省电、休眠或网络状态延后自动任务。点击刷新直接同步，期间可能出现一条临时状态通知，完成后移除。并发刷新共用同一次请求，失败时保留缓存并清除同步状态。

### 三星 S22+ / One UI

进入应用 **设置 → 允许后台更新**，打开系统应用设置，在「电池」中选择「不受限制」。在手机的「电池」（部分版本称「电池与设备维护」）→「后台使用限制」中，将 **Codex 余量**加入「从不自动休眠的应用程序」，并移出深度休眠列表。这可以避免 One UI 暂停自动更新，系统休眠与离线仍可能推迟同步。[三星官方说明](https://developer.samsung.com/mobile/app-management.html)

提醒默认关闭，可单独启用低额度、额度恢复和重置券即将到期提醒。Android 13 以上首次开启提醒会请求通知权限。提醒依赖成功同步后的数据，不能在完全离线期间保证及时送达。

额度记录来自当前账户在这台手机上的采样，保留最近 7 天；没有同步的时段不补造数据。记录页面可以清除采样。概览的 **分享额度卡片**会生成当前页面截图，打开系统分享菜单，由你选择接收应用。

## 登录与数据

登录凭据使用 Android Keystore 的 AES-GCM 加密保存，应用禁用系统备份。登录密码在浏览器的 OpenAI 页面输入。安装文件不包含用户登录凭据。

本应用直接请求 Codex 开源实现使用的账户服务：读取账户用量、读取重置券详情，以及用户确认的兑换。正常刷新不会发起模型推理。账户额度跨任务共享；显示的剩余值为 `100 - used_percent`。

这是个人账户工具，接口随 Codex 服务更新可能需要适配。接入协议及来源见 [PROTOCOL.md](PROTOCOL.md)；后台桌面能力以 [Android 小组件文档](https://developer.android.com/develop/ui/views/appwidgets/overview)为准。

## 构建

源码使用原生 Android Java 与系统 API，不依赖第三方运行库。当前版本 **1.3.0**。执行 `bootstrap.ps1` 准备经过校验的 JDK 17 和 Android SDK，再执行 `build.ps1` 生成签名 APK。`generate-reset-sounds.py` 使用 Python 标准库生成内置的原创 WAV，可选运行；声音已经包含在源码资源中。签名密钥只在构建机的 `.signing` 目录保存，保留它可以安装后续同签名更新。源码包不含该密钥。

验证用的 APK 位于 `app/src/androidTest`，使用模拟账户测试不确定结果重试、重复点击、身份校验、小组件布局、两条额度恢复和系统桌面后台刷新。它不会随正式应用发布。后台测试在原生桌面实际点击组件刷新，验证手动更新、重复点击合并、失败后保留数据、定时任务和排期稳定性，全程没有打开主界面，也没有消耗真实重置券。One UI 的实际设置仍需在手机上开启。
